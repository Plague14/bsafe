## Detalhes por Competidor

### 1. Casa
**Site:** [casa.io](https://casa.io/inheritance)

**Planos:**
| Plano | Preço | Recursos |
|-------|-------|----------|
| Standard | $250/ano (~$21/mês) | 3-key vault, inheritance básico |
| Premium | $2,100/ano (~$175/mês) | 5-key vault, inheritance completo |

**Como funciona:**
- Multi-signature (multisig) com chaves distribuídas
- Casa mantém 1 chave, usuário mantém 2-4
- Herança requer verificação legal (certidão de óbito)
- Suporte humano incluído

**Prós:**
- Interface polida e profissional
- Suporte ao cliente excelente
- Aceita ETH, USDT, USDC além de BTC

**Contras:**
- Caro para usuários pequenos
- Custodial parcial (Casa tem 1 chave)
- Apenas Bitcoin no plano Standard

---

### 2. Vault12
**Site:** [vault12.com](https://vault12.com/pricing/)

**Planos:**
| Plano | Preço | Recursos |
|-------|-------|----------|
| Basic | Grátis | Backup básico |
| Backup | Pago | Backup decentralizado |
| Inheritance | $1/dia (~$365/ano) | Herança completa |

**Como funciona:**
- Sistema de "Guardians" (pessoas de confiança)
- Guardians guardam fragmentos da chave
- Processo de herança via consenso dos Guardians
- 50% desconto pagando com token VGT

**Prós:**
- Totalmente non-custodial
- Multi-chain
- Sistema social (guardians)

**Contras:**
- Depende de pessoas de confiança
- Complexo para configurar
- Preço similar a Casa Standard

---

### 3. Unchained
**Site:** [unchained.com](https://www.unchained.com/inheritance)

**Planos:**
| Plano | Preço | Recursos |
|-------|-------|----------|
| Personal Vault | Grátis 1º ano, $250/ano depois | Vault + inheritance |
| Inheritance Boot Camp | Consultar | Programa completo com advisors |

**Como funciona:**
- Collaborative custody (2-of-3 multisig)
- Unchained + usuário + backup key
- Inheritance Protocol com verificação legal
- Parceria com consultores financeiros

**Prós:**
- 1º ano grátis
- Programa educacional incluído
- Foco em Bitcoin

**Contras:**
- Apenas Bitcoin
- Requer verificação de identidade
- EUA-centric

---

### 4. Safe Haven / Inheriti
**Site:** [inheriti.com](https://inheriti.com/)

**Preços:**
| Item | Custo |
|------|-------|
| Setup do plano | 10,000 SHA tokens (~$5-15 USD*) |
| Taxa adicional | €4.99 por setup |
| Backup shares | +2,000 SHA por share |

*Preço do SHA varia

**Como funciona:**
- Utiliza blockchain VeChain
- Trust Alliance Network (TAN) - rede de entidades legais
- Shamir Secret Sharing para fragmentar chaves
- Totalmente decentralizado

**Prós:**
- Verdadeiramente decentralizado
- Baixo custo
- Patente própria

**Contras:**
- Depende do token SHA
- VeChain menos popular
- Interface menos polida

---

### 5. Sarcophagus
**Site:** [sarcophagus.io](https://sarcophagus.io/)

**Preços:**
| Item | Custo |
|------|-------|
| Gas fees | Variável (Ethereum) |
| Archaeologist fees | Variável (mercado) |
| SARCO token | Necessário para pagamentos |

**Como funciona:**
- Dead man's switch decentralizado
- "Archaeologists" são nodes que guardam dados encriptados
- Dados liberados após período de inatividade
- Armazenamento permanente via Arweave

**Prós:**
- 100% decentralizado
- Open source
- Sem empresa centralizadora

**Contras:**
- Complexo de usar
- Dependente de gas Ethereum (caro)
- Sem suporte humano

---

### 6. Nunchuk
**Site:** [nunchuk.io](https://nunchuk.io/)

**Planos:**
| Plano | Preço | Recursos |
|-------|-------|----------|
| Free | Grátis | Wallet básica |
| Honey Badger | $8/mês (~$96/ano) | Inheritance automático |

**Como funciona:**
- Timelock nativo do Bitcoin
- Após período de inatividade, chave Nunchuk é removida
- Beneficiário ganha controle total
- On-chain, sem intermediários

**Prós:**
- Mais barato
- Verdadeiramente on-chain
- Automático (dead man's switch)

**Contras:**
- Apenas Bitcoin
- Sem verificação legal
- Risco de trigger acidental

## Oportunidade para BSafe

### Gap no Mercado

1. **Solana não tem competidor direto** - Todos focam em Bitcoin/Ethereum
2. **Preços altos** - Casa cobra $250-2100/ano
3. **Complexidade** - Sarcophagus/Inheriti são difíceis de usar
4. **Custodial** - Casa/Unchained mantêm chaves

### Posicionamento BSafe

```
┌─────────────────────────────────────────────────────────────┐
│                        BSafe                                 │
├─────────────────────────────────────────────────────────────┤
│  ✅ Solana (rápido, barato)                                 │
│  ✅ 100% Non-custodial                                      │
│  ✅ On-chain (smart contract)                               │
│  ✅ Baixo custo (taxa só no claim)                          │
│  ✅ Interface simples                                       │
│  ✅ Deadman switch + Certidão                               │
└─────────────────────────────────────────────────────────────┘
```

### Sugestão de Preço BSafe

Baseado na pesquisa:

| Modelo | Preço Sugerido | Justificativa |
|--------|----------------|---------------|
| **Criação** | GRÁTIS | Atrair usuários, sem barreira |
| **Taxa de Claim** | 0.5% - 1% | Só paga quando usa |
| **Premium (opcional)** | 0.5 SOL único | Remove taxa de claim |

**Por que 0.5% - 1%?**
- Mais barato que Casa ($250/ano em vault de $25k = 1%)
- Mais simples que Safe Haven (sem token próprio)
- Alinhado com valor entregue
- Competitivo com mercado
